# METROPULSE_SQL_Project
A SQL portfolio project analyzing Bengaluru Metro ticketing and transaction data using MySQL, relational database design, joins, subqueries, and analytical queries.

## Project Overview
MetroPulse is a SQL-based data analytics project focused on Bengaluru Metro ticketing and transaction data.
The project analyzes transaction patterns, compares payment channels, and identifies daily and yearly trends using MySQL.

## Project Objectives
- Analyze daily metro transactions.
- Compare smart card, pass, ticket, and QR transactions.
- Identify dates with high transaction volumes.
- Analyze QR payment channel performance.
- Generate meaningful business insights using SQL.

## Database Structure
The project contains 8 tables:
1. dates
2. smart_card_transactions
3. pass_transactions
4. ticket_transactions
5. qr_transactions
6. qr_channels
7. qr_channel_types
8. daily_summary

## SQL Concepts Used
- Database and table creation
- Primary keys and foreign keys
- DESC command
- SELECT queries
- INNER JOIN
- Multiple table JOINs
- Subqueries
- Aggregate functions such as AVG() and MAX()

## Key Business Insights
- Smart cards were the most-used transaction category.
- Tokens were the second-highest transaction category.
- QR transactions showed significant digital ticketing adoption.
- WhatsApp was the leading QR channel.
- Overall transaction activity peaked on 14 August 2026.
